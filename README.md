A retro flat-style travel poster for NIMBARA — the city above the clouds. A floating-island city in a golden sunset, crowned by the glowing Beacon Tower, with a daily airship service from the valley, smaller drifting islands, and a waterfall pouring from the main island into the sea of clouds below. "Where the clouds come to rest."

## Run it

```sh
node main.ts
```

This writes the poster to `/output/entry.png` (1024×1024 PNG) and verifies the written bytes match the bundled image byte for byte. It needs no network.
